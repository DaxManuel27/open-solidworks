# 23. Separately licensed products

Overview of [catalog section 23](../solidworks-feature-catalog.md#23-separately-licensed-products). See the [README](README.md) for sources and conventions.

These are separate products. They're likely out of scope for OpenForge's core, so this page summarises each one's main capabilities to scope integrations or plug-ins rather than giving option-level specs.

| Product | Main capabilities |
| --- | --- |
| Simulation Standard | Linear static, time-based motion, fatigue (high cycle), trend tracker, design studies |
| Simulation Professional | Adds frequency, buckling, thermal (steady and transient), drop test, pressure vessel, submodeling, topology optimisation, event-based motion |
| Simulation Premium | Adds nonlinear static and dynamic, linear dynamics (modal time history, harmonic, random vibration, response spectrum), composites |
| Motion | Rigid-body dynamics with forces, contact, friction, springs and dampers; results plots of displacement, velocity, acceleration, reaction forces; exports loads to Simulation |
| Flow Simulation | CFD: internal/external flow, heat transfer, conjugate heat, rotating regions, porous media, HVAC and electronics cooling modules; goals, parametric studies, cut plots, flow trajectories |
| Plastics | Injection molding fill, pack, cool and warp; gate locations, runners, cooling lines; defect prediction (weld lines, air traps, sink marks) |
| Electrical Schematic and 3D | Schematic and line diagrams with symbol libraries, wire numbering, terminal strips, PLC; routes wires and cables in 3D assemblies; reports and BOMs |
| PDM Standard and Professional | Vault with check in/out, versions and revisions, workflows with states and transitions, permissions, search, replication (Professional), ERP integrations |
| Manage | Projects, processes, items and BOM management, resource planning on top of PDM |
| CAM (and CAMWorks) | Feature recognition for machining, 2.5-axis milling and turning (Standard), 3-axis and multi-axis (Professional), toolpath simulation, post processors |
| Inspection | Ballooning drawings and PDFs, characteristic extraction, inspection reports (First Article, AS9102), CMM data import |
| Composer | Technical illustrations and animations from CAD for manuals; vector and raster outputs, interactive players |
| Visualize | GPU ray tracing, studio scenes, animations, VR and panoramas |
| MBD | DimXpert and 3D PDF publishing (see [section 16](16-tolerancing-and-mbd.md)) |
| eDrawings Professional | Markup, measure, section, move components, stamp, AR/VR viewing |
| DraftSight | 2D CAD compatible with DWG |
